# rimalxd-security-toolkit

Beginner-friendly Python security utilities created while learning cybersecurity and programming.

## Tools

### 1. Password Strength Checker

`password_checker.py`

Checks basic password characteristics such as:

- Minimum length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

### 2. SHA-256 Hash Generator

`hash_generator.py`

Converts text into a SHA-256 cryptographic hash using Python's built-in `hashlib` library.

### 3. File SHA-256 Checker

`file_hash_checker.py`

Calculates the SHA-256 hash of a local file.

## Technologies

- Python
- hashlib
- Regular Expressions
- File Handling

## Purpose

This project is part of my cybersecurity learning journey.

The goal is to understand fundamental security concepts by building small tools and experimenting with Python.
